Set Up VendNovation

Connect your VendNovation account to monitor vending machines, inventory, and sales.

1

Get API Access

Email api-request@vendnovation.com with your Organization Name and login email. They'll send your API key.

2

Create an API User

In VendNovation, create a user for API access (e.g. api@yourorg.com) with a strong password.

3

Add Environment Variables

Add these to your Render dashboard (or .env file):

VENDNOVATION_API_KEY=your_aws_api_gateway_key
VENDNOVATION_USERNAME=api@yourorg.com
VENDNOVATION_PASSWORD=your_password
4

Redeploy

Restart your app and refresh this page. Your machines will appear below.
